## Text

Cells were cultured under hypoxia (1% O2) or normoxia for 24 h. Target gene expression was quantified by qPCR using the ΔΔCt method with GAPDH as the reference gene. Each condition was run in technical triplicate (n = 3), and VEGFA was induced 4.2-fold under hypoxia (p < 0.001).

## Notes

- Original answer (handwritten): GAPDH本身受缺氧诱导，不适合作缺氧实验的内参，应验证内参稳定性或用多个内参；技术三复孔被当成n=3，缺独立生物学重复；统计建立在伪重复上；引物效率和熔解曲线未报告
- 映射：GAPDH在缺氧下不稳定、引物效率和熔解曲线未报→R12（内参与归一化）；技术三复孔当n=3→R02；统计建立在伪重复上→R03。不应报：normoxia对照是存在的（R01不应被触发）。
